# Road-Rescue

Road Rescue is a mobile application designed to provide real-time on-road assistance and travel support.
It helps users during vehicle breakdowns, emergencies, and unpredictable road conditions.
Core features include GPS tracking, SOS alerts, chatbot guidance, and traffic/weather updates.
The app connects users with nearby workshops, hospitals, gas stations, and hotels.
Carpooling and basic car repair tutorials add further value for travelers.
The target audience includes general drivers, tourists, and emergency-prone travelers.
It is built for Android using Java (Spring) and XAMPP for backend support.
The app’s architecture includes a detailed ER diagram and relational schema.
Use case diagrams and timelines are included for structured planning and implementation.
Overall, Road Rescue aims to boost travel safety, support, and convenience on the go.
